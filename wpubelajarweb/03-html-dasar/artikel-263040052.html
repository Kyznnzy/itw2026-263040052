Perkembangan Teknologi Web di Era Modern

Teknologi web telah berkembang sangat pesat sejak pertama kali diperkenalkan oleh Tim Berners-Lee pada tahun 1989. pada awal kemunculannya, halaman web hanya berupa dokumen teks statis yang terhubung melalui pautan (hyper).

peran penting HTML

HTML (HyperText Markup Language) merupakan bahasa marka standar yang menjadi fondasi utama dalam membangun struktur halaman web tanpa HTML, peramban tidak akan menampilkan tesk, gamabr, maupun elemen interaktif secara terstruktur
